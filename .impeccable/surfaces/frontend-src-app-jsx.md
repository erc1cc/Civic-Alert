# Surface: SD Voice Town Hall site (landing `/` + live map `/map`)

Scope: replacement visual world for the whole site. Landing is Persuade (judges, first contact); `/map` is Operate (the working demo). Audience and truth live in PRODUCT.md.

## Direction contract

THESIS: A voice report becomes one honest pin. Pinned by the user: mimic clarte.io's visual grammar. Refuses the navy civic-dashboard shell and the centred-hero-plus-card-row landing.

OWN-WORLD: Off-white ground #f8f8f7, ink #1a1a1a, grey continuation text; Inter Tight 400 with tight tracking for all headings, two-tone headlines (ink clause, grey continuation); Geist Mono only for data and metadata (IDs, radii, speaker labels, timestamps); hairline rules on a column grid; 4px controls, 8px cards; dark night sections (#0d0f12) with translucent floating cards. Colour does one job: muted tier ramp (Tier 1 red, then ink and greys); call volume heat in blueprint blue. One state colour is allowed: muted green #2f6b4a only for the done state (approved for crew, resolved), because an Operate surface needs a visible success state and it never competes with the tier ramp.

STORY: A judge learns the loop (call → pin → verify → review → decay) on the landing page, then opens the live map and plays a sample call.

FIRST VIEWPORT: Landing: full-bleed dark San Diego map with real seed pins drawn as faint halos (desktop: the city is offset so the halos sit in the right third beside the copy; below 768px the map is masked out of the copy band and carries no halos, because on a 390 hero every pin would print through the text), centred two-tone headline, white "Play a sample call" plus ghost "Open the live map" (swapped from the first draft: the header already carries a white "Open the live map", and the call is the faster proof for a judge), four floating call/location/review cards around it. Map: hairline header, map left, sidebar right; during a sample call a dark floating call card on the map edge shows the transcript live.

FORM: User-pinned reference (clarte.io); the concept roll was skipped because a user-pinned direction beats the roll. seed: none (skipped, user-pinned)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
